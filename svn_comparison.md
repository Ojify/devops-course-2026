1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"? 
В Git ветка — это просто указатель на коммит, в SVN — копирование директорий.

2. Можно ли в SVN сделать коммит без интернета? Почему? 
Нет, SVN централизованная, коммит идет на сервер. В SVN репозиторий один и находится на сервере. На компьютере — только рабочая копия (working copy), а не полный репозиторий с историей. Команда svn commit не сохраняет изменения локально, а отправляет их на сервер, где создаётся новая ревизия.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git? 
Legacy-проекты, госсектор, банки, где важна строгая централизация.
